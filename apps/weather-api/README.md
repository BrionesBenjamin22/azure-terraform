# Weather API

Servicio previsto en Python y FastAPI para consultar información meteorológica por ciudad mediante una API externa.

## Estado

Pendiente de implementación. Esta etapa no incluye código, dependencias, endpoints ni configuración de contenedores.

## Alcance técnico previsto

- Servicio sin estado.
- Configuración mediante variables de entorno, ConfigMaps y Secrets.
- Comprobaciones de salud.
- Despliegue independiente en Kubernetes.

El contrato HTTP, las validaciones, los permisos y los errores se documentarán cuando se diseñe el servicio.
