# Secure Notes API

Servicio previsto en Python y FastAPI para administrar usuarios, autenticación y notas privadas con persistencia en PostgreSQL.

## Estado

Pendiente de implementación. Esta etapa no incluye código, dependencias, endpoints, autenticación ni configuración de contenedores.

## Alcance técnico previsto

- Registro y autenticación de usuarios.
- Autorización mediante JWT.
- Gestión de notas privadas por usuario.
- Persistencia y volúmenes en Kubernetes.
- Auditoría y protección de endpoints críticos.

El contrato HTTP, las validaciones, los permisos, el modelo de datos y los errores se documentarán cuando se diseñe el servicio.
