# Kubernetes

Esta carpeta contendrá los manifiestos declarativos necesarios para desplegar las aplicaciones y sus dependencias en Kubernetes.

## Estado

Pendiente de implementación. Durante el bootstrap no se crean Deployments, Services, ConfigMaps, Secrets, volúmenes ni recursos de escalamiento.

Los manifiestos deberán utilizar configuración reproducible y nunca incluir credenciales o secretos reales.
